THE BAY LAWN CLUB: uploading to Hostinger
=========================================

baylawnclub-site.zip holds the whole site (18 files, all at the top level):
  index.html, manifesto.html, weekly-meet.html, founder.html,
  membership.html, get-involved.html, privacy.html, terms.html, style.css, site.js, founder.jpg,
  favicon.svg, favicon.ico, favicon-32.png, apple-touch-icon.png,
  og-image.jpg, robots.txt, sitemap.xml

Steps
1. Log in to hPanel (hpanel.hostinger.com), then Websites > baylawnclub.com > Manage.
2. Open Files > File Manager.
3. Go into the public_html folder. If Hostinger put a default index.php or
   default.php there, delete it, or it may show instead of the site.
4. Click Upload (top right) and choose baylawnclub-site.zip.
5. Right-click the uploaded zip > Extract, and extract into public_html itself
   (the path should be just "public_html", not a new subfolder).
6. Delete the zip from public_html afterwards.
7. Visit https://baylawnclub.com and check the home page loads.
   In hPanel > Security > SSL, make sure the free SSL is installed so it opens on https.

Waitlist form
- Submissions go straight to the Google Sheet "Bay Lawn Club Waitlist" in my Drive.
- The script behind it is the Apps Script project "Bay Lawn Club Waitlist Form"
  (open it from the sheet via Extensions > Apps Script). A copy of the code is in
  apps-script/Code.gs in the project folder.
- If you ever edit the script, use Deploy > Manage deployments > edit (pencil) >
  Version: New version, so the web address stays the same.

If changes don't show after uploading
- Hostinger tells browsers to keep style.css and site.js for 7 days. Each HTML
  page loads them as style.css?v=... and site.js?v=...; bump that version on
  every update so browsers fetch the new files.
- Also: hPanel > Websites > Manage > Performance > CDN > Purge cache, then
  reload with Cmd+Shift+R.
